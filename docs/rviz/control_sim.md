# RViz profiles: JTAC, F/T sensing, safety and teleop, simulators, tool trace

Open any profile with `ros2 launch mp_rviz view.launch.py profile:=<name>` (add `use_sim_time:=true` under a simulator and
`markers:=true` to also start `mp_viz_markers.py`).

**Nothing here was run in RViz.** Topics, frames and message types come from the sources (grep of the nodes, launch files and
READMEs); the profiles were only checked as valid YAML with a fixed frame and displays (`python3 -m pytest src/common/mp_rviz/test`).
"No messages received" on a display means its producer is not running (or has a different topic or QoS); a TF error means
the fixed frame does not exist in your setup.

Parameters of `mp_viz_markers.py`: `force_topic`, `feedback_topic`, `tool_frame` (`tcp_link`), `fixed_frame` (`base_footprint`),
`force_limit_n`, `trace_max_points`, `trace_min_step_m`, `rate_hz`. Set one with
`ros2 run mp_rviz mp_viz_markers.py --ros-args -p force_limit_n:=30.0`.
