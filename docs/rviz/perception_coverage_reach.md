# RViz profiles: perception, coverage, reachability, stands, manager

Open any of these with `ros2 launch mp_rviz view.launch.py profile:=<name>` (add `markers:=true` to also start
`mp_viz_markers.py`, which publishes `/mp_viz/mission_text` and `/mp_viz/tool_trace`).

**Honesty note.** None of these profiles has been opened in RViz. Topic names, frames and message types were taken
from the nodes' source and launch files; the profiles were checked only as valid YAML by
`src/common/mp_rviz/test/test_profiles.py`. A display that shows "No messages received" or a TF error usually means
the producer is not running or the Fixed Frame needs changing (Global Options) to the frame of your data.

## Topics looked for and not found

- wall_detector: any plane marker or republished cloud; only `~/wall_scene` (String JSON).
- scene_model, scene_adapters: no ROS publishers at all (libraries).
- reachability, reachability_moveit: no marker or map publisher; services and a log-only probe.
- stand_navigator: no stand, goal or path publisher; `/map` and `/trial_map` come from coverage_planner scripts.
- manipulation_manager: no marker, status or state publisher.
